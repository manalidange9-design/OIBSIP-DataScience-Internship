# 🌸 Iris Flower Classification

## 📌 Project Description
The Iris Flower Classification project uses machine learning
algorithms to classify iris flowers into Setosa, Versicolor,
and Virginica based on their physical measurements.

## 🎯 Objective
To build and evaluate machine learning models that predict
iris flower species using their sepal and petal measurements.

## 📊 Dataset
The Iris dataset is built into the Scikit-learn library.

- Total Samples: 150
- Features: 4
- Target Classes: 3
- Species: Setosa, Versicolor, Virginica

### Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## ⚙️ Project Workflow
1. Load the Iris dataset.
2. Perform Exploratory Data Analysis (EDA).
3. Check missing values and descriptive statistics.
4. Visualize data using pairplots and boxplots.
5. Split data into training and testing sets.
6. Train Logistic Regression and K-Nearest Neighbours models.
7. Evaluate models using accuracy, precision, recall,
   F1-score, and confusion matrices.
8. Compare models and select the best-performing model.
9. Predict the species of a new flower.

## 📁 Project Files

- `Iris_Screenshots.pdf` — Screenshots of the project and outputs.

## 📈 Expected Outcome
A trained machine learning model that predicts iris flower
species based on physical measurements and compares the
performance of different classification algorithms.

## ✅ Conclusion
The project demonstrates how machine learning can classify
iris flowers using Logistic Regression and K-Nearest Neighbours.
The models are evaluated and compared to identify the
best-performing classifier.
