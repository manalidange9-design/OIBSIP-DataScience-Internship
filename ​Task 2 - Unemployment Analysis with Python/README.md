# OIBSIP Task 2: Unemployment Analysis with Python

## 📌 Project Description
This project analyzes unemployment trends in India using Python. It uses data analysis and visualization techniques to examine regional differences and changes in unemployment rates before and after COVID-19.

## 🎯 Objective
- Analyze unemployment rates across Indian states.
- Identify monthly and yearly unemployment trends.
- Compare unemployment rates before and after COVID-19.
- Visualize unemployment patterns using charts and graphs.

## 📊 Dataset
The project uses the **Unemployment in India** dataset, which contains information about regions, dates, unemployment rates, estimated employment, and labour participation rates.

**Source:** Kaggle – Unemployment in India

## 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## ⚙️ Project Workflow
1. Load the unemployment dataset.
2. Inspect and clean the data.
3. Handle missing values and convert data types.
4. Perform Exploratory Data Analysis (EDA).
5. Create charts and visualizations.
6. Compare pre-COVID and post-COVID unemployment rates.
7. Analyze results and draw conclusions.

## 📈 Key Visualizations
- Region-wise average unemployment rate.
- Monthly unemployment trends.
- Unemployment trends across three regions.
- Top 10 regions with the highest average unemployment.
- Correlation heatmap.
- Pre-COVID vs. post-COVID comparison.
- Year-wise unemployment analysis.

## ✅ Expected Outcome
The project identifies unemployment patterns, regional differences, and changes in unemployment rates over time through data analysis and visualization.

## 📝 Conclusion
This project uses Python to analyze unemployment trends in India. The visualizations provide insights into regional variations and changes in unemployment rates before and after COVID-19.
