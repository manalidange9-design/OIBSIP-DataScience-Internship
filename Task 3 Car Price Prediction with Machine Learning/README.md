# 🚗  Task -3 Car Price Prediction with Machine Learning

## 📌 Project Description
This project predicts the selling price of used cars using machine learning. It analyzes features such as car brand, age, kilometers driven, fuel type, and transmission to estimate car prices.

## 🎯 Objective
- Predict used-car selling prices.
- Analyze factors affecting car prices.
- Train and compare regression models.
- Evaluate model performance.

## 📊 Dataset
The project uses a used-car dataset from Kaggle containing car details and selling prices.

**Dataset Source:** [Kaggle Car Price Datasets](https://www.kaggle.com/datasets?search=car+price+prediction)

## 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## ⚙️ Project Workflow
1. Dataset collection and loading
2. Data cleaning and preprocessing
3. Feature engineering
4. Exploratory Data Analysis (EDA)
5. Categorical feature encoding
6. Correlation heatmap visualization
7. Training and testing data split
8. Model training using Linear Regression and Random Forest
9. Model evaluation using MAE, RMSE, and R²
